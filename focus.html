Focus

The recurring technical areas behind Mystrowin projects: practical software, systems work, and experimentation close to the operating system.

Direction Windows-first, systems-heavy.

The work increasingly centers on filesystems, compression, runtime behavior, and OS integration.

01

Utilities

Desktop software built around reducing friction in real workflows, with a preference for direct native behavior over unnecessary abstraction.

02

Systems

Filesystems, Windows integration, runtime architecture, storage behavior, and lower-level engineering where correctness matters as much as interface design.
