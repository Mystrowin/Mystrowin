# Mystrowin

Source for [mystrowin.com](https://mystrowin.com/), an independent software and research portfolio.

## Destinations

- [Arqivexa](https://arqivexa.mystrowin.com/): Windows archive workspace, product information, downloads, and source.
- [Mystrowin Research](https://research.mystrowin.com/): technical research, papers, and supporting materials.

The site is a static multi-page HTML/CSS/JavaScript portfolio with accessible navigation, search metadata, an XML sitemap, and outbound-link attribution.
