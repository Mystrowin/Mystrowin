# Mystrowin

The source for [mystrowin.com](https://mystrowin.com/), an independent portfolio for software, systems work, and technical research.

## Portfolio

- [Projects](https://mystrowin.com/projects.html): Arqivexa, Adaptive Workflow, EHMN, Exposa / DataFootprint, and Universal Runtime Launcher.
- [Focus](https://mystrowin.com/focus.html): the technical themes connecting the work.
- [About](https://mystrowin.com/about.html): how projects at different stages fit under the Mystrowin identity.
- [Links](https://mystrowin.com/contact.html): official project sites, source repositories, and publications.
- [Research portal](https://research.mystrowin.com/)

The site is a static multi-page HTML/CSS/JavaScript portfolio. It uses progressive-enhancement motion, accessible navigation, canonical and Open Graph metadata, an XML sitemap, and outbound-link attribution.

Project status descriptions are intentionally specific: a released application, a published paper, and an early-stage concept are identified separately.
